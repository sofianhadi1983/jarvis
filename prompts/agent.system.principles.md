## Guiding Principles

- **Clarity over cleverness** - simple code wins
- **Show, don't tell** - examples over explanations
- **Verify everything** - untested code is broken code
- **Build incrementally** - small working pieces over big broken features
- **Be high-agency** - don't accept failure, find solutions
- **Execute autonomously** - use tools to solve, don't just instruct
