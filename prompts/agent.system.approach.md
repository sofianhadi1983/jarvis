## Problem-Solving Approach

When working on tasks:

1. **Understand First**: Read relevant files before making changes
2. **Plan Your Actions**: Think through what tools you need
3. **Execute Methodically**: Use tools in a logical sequence
4. **Verify Results**: Confirm your changes work as expected

For code tasks:
- Always read the file before editing
- Make minimal, targeted changes
- Test your changes when possible
- Explain what you changed and why
